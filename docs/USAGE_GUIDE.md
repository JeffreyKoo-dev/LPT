# 사용법 가이드

LPT를 처음 사용하는 사용자 기준으로, 화면 순서대로 사용 방법을 안내합니다.

## 1. 홈 (`/`)

서비스 소개와 핵심 컨셉(사주, 성향 설문, 라이프스타일 인디케이터, 성장 퀘스트,
레벨업/뱃지)을 확인할 수 있습니다. **"내 라이프 패턴 분석 시작하기"** 버튼을
누르면 `/start`로 이동합니다.

> 모든 결과는 확정된 운명이 아니라, 참고할 수 있는 경향과 가능성으로 제공됩니다.

## 2. 기본 정보 입력 (`/start`)

캐릭터 카드에 표시될 정보를 입력합니다.

| 항목 | 설명 |
| --- | --- |
| 닉네임 | 캐릭터 카드 및 공유 카드에 표시 (최대 20자) |
| 양력/음력 | 생년월일의 달력 기준 선택 |
| 생년월일 | 사주 계산에 사용 |
| 출생시간 | 시주(시간 기둥) 계산에 사용. 모르면 "출생시간을 모릅니다" 체크 |
| 성별 | 사주 계산 참고용 |

입력한 정보는 **이 기기의 브라우저에만** 저장되며, 외부로 전송되지 않습니다.
완료 후 **"성향 설문으로 이동하기"**를 누르면 `/survey`로 이동합니다.

## 3. 성향 설문 (`/survey`)

총 36문항, 문항당 5점 척도(전혀 그렇지 않다 ~ 매우 그렇다)로 응답합니다.
답을 고르면 자동으로 다음 문항으로 넘어가며, 상단 진행률 바에서 남은 문항을
확인할 수 있습니다. "이전" 버튼으로 되돌아가 답을 수정할 수 있습니다.

브라우저를 닫았다가 다시 들어와도 마지막으로 답하지 않은 문항부터 이어서
진행됩니다. 36문항을 모두 마치면 자동으로 분석이 실행되고, 산출된 LPT 유형
미리보기가 표시됩니다. **"결과 리포트 보기"**를 눌러 `/result`로 이동하세요.

## 4. 결과 리포트 (`/result`)

분석이 끝나면 아래 내용을 확인할 수 있습니다.

- **캐릭터 카드**: LPT 유형명, 판타지 클래스명, 역할군, 대표 스탯, 오행 기운
- **오늘의 LPT 카드**: 오늘 날짜 기준으로 도움이 될 수 있는 짧은 팁 (매일 바뀜)
- **오행 분포**: 목/화/토/금/수 비중을 레이더 차트로 표시
- **성향 점수**: 에너지 방향(E/I) · 정보 인식(S/N) · 판단 기준(T/F) · 생활 방식(J/P) 4축
- **십성**: 일간 기준으로 년주·월주·시주와의 관계 해설
- **라이프스타일 인디케이터**: 일하는 방식 · 관계 방식 · 생활 리듬 · 성장 방향
- **성장 시너지 / 성장 포인트**: 강점으로 활용할 수 있는 부분과, 채워가면 도움이
  되는 부분을 구분해서 제시

하단의 **"성장 대시보드로 이동"**을 눌러 본격적으로 퀘스트를 진행할 수 있습니다.

## 5. 성장 대시보드 (`/dashboard`)

캐릭터의 현재 상태를 한눈에 보여줍니다.

- **레벨/경험치**: 현재 레벨과 다음 레벨까지 필요한 XP
- **스탯**: 활력 · 통찰 · 조율 · 지구력 (캐릭터의 대표 스탯이 강조 표시됨)
- **뱃지**: 획득한 뱃지 수 / 전체 뱃지 수
- **성장 퀘스트**: 완료한 퀘스트 수, "퀘스트 보기" 버튼으로 `/quests`로 이동
- **캐릭터 카드 공유하기**: 캐릭터 카드를 이미지로 공유 (아래 8번 참고)

## 6. 퀘스트 (`/quests`, `/quests/[id]`)

`/quests`에서는 13개의 성장 퀘스트가 목록으로 표시되며, 캐릭터의 대표 스탯과
관련된 퀘스트에는 **"추천"** 표시가 붙습니다. 이미 완료한 퀘스트는 흐리게
표시되고 **"완료됨"**으로 안내됩니다.

퀘스트를 선택하면 상세 화면(`/quests/[id]`)에서 설명과 보상(XP, 스탯)을 확인하고
**"퀘스트 완료하기"**를 누를 수 있습니다. 완료 시:

- XP와 관련 스탯이 즉시 상승합니다.
- 레벨업 조건을 만족하면 레벨업 안내와 함께 **"레벨업 카드 공유하기"** 링크가
  표시됩니다.
- 새로운 뱃지 획득 조건을 만족하면 획득한 뱃지 목록과 함께 **"뱃지 카드
  공유하기"** 링크가 표시됩니다.

## 7. 성장 히스토리 (`/growth`)

지금까지의 퀘스트 완료, 레벨업, 뱃지 획득 기록을 최신순 타임라인으로
확인할 수 있습니다. 각 항목에는 발생 일시와 상세 내용이 함께 표시됩니다.

## 8. 뱃지 (`/badges`)

전체 8종 뱃지의 획득 여부를 한눈에 볼 수 있습니다. 획득한 뱃지는 획득 날짜와
함께 별 아이콘으로 표시되며, **"공유하기"** 링크로 해당 뱃지의 공유 카드를
만들 수 있습니다. 아직 획득하지 못한 뱃지는 물음표 아이콘으로 흐리게 표시됩니다.

| 뱃지 | 획득 조건 |
| --- | --- |
| 첫 발걸음 | 퀘스트 1개 완료 |
| 꾸준한 모험가 | 퀘스트 5개 완료 |
| 퀘스트 마스터 | 퀘스트 10개 완료 |
| 성장의 시작 | 레벨 3 달성 |
| 안정 궤도 | 레벨 5 달성 |
| 정점의 캐릭터 | 레벨 10(만렙) 달성 |
| 균형 잡힌 성장 | 4개 스탯 모두 20 이상 |
| 특화된 강점 | 한 스탯이 40 이상 |

## 9. 공유 카드 (`/share/[id]`)

캐릭터 카드, 레벨업, 뱃지 획득 순간을 이미지 카드로 만들어 공유할 수 있습니다.
접근 경로는 세 가지입니다.

- 캐릭터 카드: 대시보드 또는 성장 히스토리 화면의 **"캐릭터 카드 공유하기"**
- 레벨업 카드: 퀘스트 완료 후 레벨업 시 표시되는 **"레벨업 카드 공유하기"**
- 뱃지 카드: 뱃지 목록 또는 퀘스트 완료 후 표시되는 **"공유하기" / "뱃지 카드 공유하기"**

카드 화면에서 할 수 있는 동작:

- **PNG로 저장하기**: 카드를 이미지 파일로 다운로드
- **링크 복사하기**: 현재 화면 URL을 클립보드에 복사

> 공유 카드에는 닉네임 · LPT 유형명 · 클래스명 · 레벨 · 뱃지명만 표시되며,
> 생년월일 · 출생시간 · 성별 · 설문 상세 응답은 절대 포함되지 않습니다.

> **주의**: 이 MVP는 별도 서버 저장 없이 현재 기기의 브라우저 데이터만으로
> 카드를 그립니다. 복사한 링크를 다른 기기·다른 브라우저에서 열면 데이터가
> 없어 안내 화면이 표시됩니다. PNG로 저장한 이미지 파일은 어디서든 정상적으로
> 공유할 수 있습니다.

## 10. 데이터 초기화

이 서비스는 브라우저의 LocalStorage에 데이터를 저장합니다. 처음부터 다시
시작하고 싶다면:

1. 브라우저 개발자 도구 → Application(또는 저장공간) → Local Storage에서
   `lpt:`로 시작하는 키를 모두 삭제하거나,
2. 설문 완료 화면의 **"설문 다시하기"** 버튼으로 설문 응답만 초기화할 수 있습니다.
   (기본 정보, 성장 프로필은 유지됩니다)
